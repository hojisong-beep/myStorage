# M0 그록 스타일 시험 — SuperGrok 수동 생성용 프롬프트

목적: 그록 이미지가 Ashen Vigil의 아트 방향(기획서 "아트 방향과 스타일 가이드")에 맞는지 비용 없이 확인합니다.

## 사용 방법

1. SuperGrok 앱(이미지 생성)에서 아래 프롬프트를 **한 개씩 통째로** 복사해 넣습니다.
   - 비율은 **1:1(정사각형)** 을 고릅니다.
   - 프롬프트마다 공통 스타일 문구가 이미 들어 있습니다.
2. 결과 중 가장 마음에 드는 1장만 내려받습니다.
3. 파일 이름을 표의 `ID`로 바꿉니다. 예: `icon_sword.png`
4. 채팅에 첨부해 주시면 제가 `ashen-vigil/assets/raw/` 에 저장하고 가공합니다.
   - 한 번에 여러 장 첨부해도 됩니다. 16장을 다 만들지 않아도 됩니다. 아이콘 6장 정도면 판단할 수 있습니다.

## 판단 기준

- 16장이 **같은 게임의 그림처럼 보이는가** (색감, 붓 터치, 조명)
- 작게 줄였을 때(64px)도 **무엇인지 알아볼 수 있는가**
- 배경이 깨끗한 검은색이라 **배경 제거가 쉬운가**
